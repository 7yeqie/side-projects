一些临时起意做的小项目。

## burton-alf-laylah-bilingual.html

《一千零一夜》Burton 英译本的英汉逐段对照阅读页。翻译进行中，会不定期更新。

在线预览：https://7yeqie.github.io/side-projects/burton-alf-laylah-bilingual.html

## yantielun-original-vernacular.html

《盐铁论》十卷六十篇原文与白话逐段对照阅读页。繁体原文常显，白话可逐段展开或用顶栏「对照模式」一键全展开；专名与说话人标签点击后以灯箱显示释义与历史背景，页尾附完整词条索引。单文件离线可用，支持明暗配色切换。

在线预览：https://7yeqie.github.io/side-projects/yantielun-original-vernacular.html
